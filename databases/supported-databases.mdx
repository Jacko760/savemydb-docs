| Database | Status | Default Port |
|---|---|---|
| PostgreSQL | Supported | 5432 |
| MySQL | Supported | 3306 |
| MongoDB | Supported | 27017 |
| SQL Server | Supported | 1433 |

## Version compatibility

savemydb works with currently maintained versions of each supported database. If you're running a significantly older version and run into issues, [contact support](mailto:support@savemydb.com) — most version-specific issues can be resolved quickly.

## Don't see your database?

savemydb is actively adding support for more database engines. If there's one you need, [let us know](mailto:support@savemydb.com).
