The [Dashboard](https://app.savemydb.com/dashboard) is your home page — a real-time view of your entire backup estate.

## Stat cards

| Card | Shows |
|---|---|
| Servers Protected | Total database connections, and how many agents they span. |
| Backups (24h) | Backup jobs run in the last 24 hours, and how many succeeded. |
| Storage Used | Total size of backups taken, across all storage destinations. |
| Issues | Number of failed jobs needing attention. |

## Server health

A card per database connection, showing its most recent backup status and a 14-day activity sparkline — a quick way to spot a server that's started failing.

## Backup activity

A 26-week heatmap, similar to a GitHub contribution graph, showing backup volume and success rate over time. Green means successful runs, red means failures.

## Needs attention

Lists your most recent failed backup runs, with the error message and which agent/database was involved — usually the fastest way to see what needs fixing.

## Agent health

Shows every installed agent, its current status, and how many database servers it's responsible for.
