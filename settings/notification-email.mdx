---
title: "Notification Email"
description: "Where backup failure alerts are sent."
---

This is the email address savemydb uses when a backup job fails. See [Notifications](/monitoring/notifications) for what triggers an alert and what it includes.

## Updating it

Go to **Settings** in the sidebar, update the **Notification Email** field, and click **Save**. Changes take effect immediately.

## Default value

If you haven't set one explicitly, this defaults to your account's login email — the one you used to sign up.

## Using a shared inbox

You can point this at a team distribution list or shared inbox instead of an individual's email, so failures aren't missed if one person is away.
